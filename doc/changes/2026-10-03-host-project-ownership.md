# Preserve host project ownership

CCC now runs native rootful Linux and WSL projects with the invoking user's UID and primary GID, using validated, cached identity images while preserving the named `ccc` account, HOME and sudo. Default images use 1000:1000; rootless Podman retains its keep-id mapping, and unsupported rootless Docker mappings fail explicitly. Writable mise caches are separated by identity, including remote image identities, and stopped lab volumes migrate only verified previous owners. Startup refuses incompatible running containers without stopping their work and leaves forwarded SSH socket permissions intact. Existing incorrectly owned host files still require the bounded, post-session repair described in [the runtime requirement](../runtime/REQ__host-project-ownership.md); updating CCC does not rewrite existing project ownership automatically.
